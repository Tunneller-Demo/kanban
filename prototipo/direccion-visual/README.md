# PROTOTIPO desechable: dirección visual del Tablero

No es código de la app. Compara tres direcciones visuales y prueba `@dnd-kit/react` en móviles reales.

```sh
npm install
npm run dev
```

Abre la URL `Network` en el móvil, en la misma red. Cambia de variante con la barra flotante o con `?variant=A|B|C`. El botón `+14` añade Pendientes para probar el desplazamiento.
